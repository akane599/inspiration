# Codebase Map — Inspiration
*Last Updated: 2026-10-21*

Shizuku-powered battery analytics and diagnostics for Android power users. Phase 2 provides the telemetry snapshot pipeline, history ingestion, Room persistence, and capture scheduling. Phase 3 adds interval metrics and the `:core:diagnostics` insight layer (rule engine R1–R4, dictionary, Battery Story) with debug `PROBE_INSIGHTS`; Phase 4 adds the leaf `:core:designsystem` module (theme tokens, components, synchronized scrubbing chart, sleep hypnogram) plus the debug-only `DesignGalleryActivity`. Phase 5 adds the app shell (bottom bar / rail, `RefreshCoordinator`), the manual-DI `AppContainer` that implements five per-feature dependency interfaces, the five MVI feature screens (Cockpit, X-Ray, Sleep Lab, Charge & Health, Toolkit), the typed privileged toolkit write path (`ToolkitActions`, AIDL txns 20–31) and the shared `AnalysisSession`. Earlier remediation added deadline-bound binder calls, monotonic-clock retention, failure containment (`attempt {}`), selection-tagged analysis and observed-change override chains. The current 2026-10-19 remediation ([`AUDIT_REPORT.md`](../../AUDIT_REPORT.md), A-01–A-24) adds capture-time UID ownership proof and Room schema v5, conservative truncated/absent-source handling, atomic charging-job scheduling, recoverable toolkit restore/admission state, measurement-scoped feature data and non-pointer interval controls. The independent 2026-10-19 audit remediation (F-01–F-25, release 0.2.3) adds:
- app-op `allow` writes (toolkit API 3) and user-0 toolkit containment;
- cross-snapshot UID identity by namespace plus owner fingerprint, proven with one bulk package read;
- a shared ±2 s battery-stats session predicate;
- the history horizon with a 2-minute grace;
- `AnalysisSession.recompute()`;
- spent-stub dead-binder recovery;
- chart handle slop and step-based tick labels.

The second independent audit's remediation (N-01–N-28, release 0.2.4) adds:
- RESET records that restate the live screen/doze state, and reference windows reconciled with capture anchors;
- a process-wide store tick (`StoreTicks`) after every history-ingesting capture, so the visible Cockpit and Health reload;
- toolkit API 4: bg-dexopt is refused below API 33, and a cancel is confirmed only by our client's exit;
- lift-only undo of Inspiration's own change on protected apps, and never-dispatched writes finalized at once;
- persisted live-current calibration, and a gauge charging state taken from status and current;
- history runs in insertion order, an ingest that skips past-retention rows, `PACKAGE_REPLACED` captures, and boots detected from the clocks;
- Sui support: a live binder outranks the manager app, and binder-backed states name the backend (SQ-29);
- a hidden-API exemption narrowed to `Sensor.getHandle()`, and release resource shrinking with en/tr locales;
- reserved AIDL txns 4/5 and dump targets 2/4, plus dead-code removal.

The third audit's remediation (R-01–R-21, branch `remediate/audit-2026-10-20`) adds proven-zero baselines for UIDs new to a complete reference, FULL screen-off captures that bind the service on demand, Room schema v6 with newest-of-kind history seeks, post-dispatch-safe toolkit outcomes, a queued Shizuku bind/unbind drainer, the status-start gate, and one shared touch guard in `:core:designsystem` with hidden overlay windows.

The 2026-10-20 board follow-ups (SQ-1–SQ-23) add consistent multi-read analysis transactions, a `STOPPED_STATE_EXIT` capture label for Android 15 stopped-state boot broadcasts, a history-only "Since screen off" with an Empty reason, a one-time history-cursor rewind for existing installs, one shared charge-state rule and calibration store for the gauge and the status notification, a plugged-in charge-counter unit check, one 24 h chart date rule, confirmed-only bg-dexopt cancels, an X-Ray count of apps hidden for lack of a baseline, Sleep Lab's culprit card for the screen-off awake rule (SQ-17), and a stored history prune watermark in Room v7 so pruned events can't be re-ingested (SQ-8).

The fourth audit's remediation ([`AUDIT_REPORT.md`](../../AUDIT_REPORT.md) B-01–B-23, branch `remediate/audit-2026-10-21`, in progress) so far adds: toolkit reconcile that credits only a prompt read-back to a PENDING write, keeping a late one as an observed, unattributed change outside Reset all (B-01); history ingests that stop at the page cap or on a failed page no longer counting as complete (`page_cap`, B-02); no batterystats history query below API 34 (B-09); app labels/icons that cache only found entries and drop on package broadcasts (`PackageChanges.kt`, B-18); Sleep Lab owner lookups limited to shown rows (B-17); Shizuku state reads and the permission request off Main with a suspending `refresh()` (B-10); epoch-tagged refresh failures (B-13); Health live readings ordered on the elapsed clock (B-15) and a stored day shown without waiting for the kernel read (B-14); Cockpit time to empty extrapolated only from a counter past the µAh floor (B-07); timeline level/temperature lines carried in at the window start and held to known history (B-05); a marker-sheet list-read failure kept apart from a capture failure (B-19); a chart that ignores a press an ancestor already consumed (B-11); app UIDs judged by app id (B-16); no all-clear when no app could be checked (`APPS_UNPROVEN`, B-03); Sleep Lab tabs and cards that name why figures are missing (`NO_SCREEN_OFF_FIGURES`, `UnavailableCause`, B-04); one shared toolkit admission rule for X-Ray and Toolkit (`ToolkitAdmission`, B-06) and a Reset-all title that counts only what it restores (B-21); X-Ray writes tracked per app with newest-read tickets (B-12); a shared UID named only by the owner its process identifies, and otherwise titled "shared by N apps" in both X-Ray and Sleep Lab (`uidIdentity`, `identifyingPackage`, B-08); a per-target bound on service dump writers (`busy`, B-20); a FULL read that takes the batterystats dump first and reuses its stats sync (B-22); and X-Ray component shares that stay within the whole for the system UID (B-23). The audit's §3 cleanup moves the debug probe's in-process IPC readers and models to `:core:shizuku-ipc`'s `src/debug`, deletes the unreferenced AIDL parcelable declarations, shares one clock and tick-label rule between both charts (`ClockLabels.kt`), and removes dead code (unread kernel fields, `unplugWindowSnapshots`, `AOSP_KEYS`, Sleep Lab's unreachable needs-full culprit state).
